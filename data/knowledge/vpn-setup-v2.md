# Thiết lập VPN demo

## Ubuntu

Cài client, nhập URL công ty demo và đăng nhập SSO. Dùng gói client được quản lý từ cổng
phần mềm; không tắt kiểm tra chứng chỉ.

## Windows

Install the managed client and authenticate through SSO. Accept the device compliance
prompt, then select the default company profile.

## Kiểm tra

Kết nối hợp lệ hiển thị tên profile, địa chỉ mạng riêng và không có cảnh báo chứng chỉ.
