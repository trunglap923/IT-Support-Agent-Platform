# GitLab access for the demo company

## Yêu cầu quyền

Gửi yêu cầu với project, role và xác nhận của quản lý. Chỉ yêu cầu mức quyền tối thiểu cần
cho công việc; quyền Owner không được cấp qua luồng hỗ trợ thông thường.

## SSH keys

Add only the public key in the user SSH Keys settings page. Never upload, paste, or attach a
private key.

## Access review

Department maintainers review membership each quarter. Access that is no longer needed must
be removed rather than shared with another user.
