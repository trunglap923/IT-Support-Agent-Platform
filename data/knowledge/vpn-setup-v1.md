# Demo VPN setup

## Ubuntu

Install the managed VPN client from the demo software portal. Enter
`vpn.demo.invalid` as the portal address and sign in through SSO. Never paste an account
password into a terminal command or support ticket.

## Windows

Install the managed Windows client and authenticate through SSO. Accept the device
compliance prompt, then select the default company profile.

## Verification

After connecting, open the client status page. A healthy connection shows the profile name,
an assigned private address, and no certificate warning.
